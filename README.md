# PIXIS-PROJECTS

PIXIS-PROJECTS contains the files and instructions needed to set up PIXIS PROJECTS.

Project are designed for users who want a simple first-time setup experience on supported hardware.

## Contents

- `docs/` user-facing installation and troubleshooting guides.
- `scripts/` bootstrap and helper scripts.
- `systemd/` first-boot service files.
- `config/` boot-time configuration files.
